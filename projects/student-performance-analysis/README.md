# Student Performance Analysis

A reproducible exploratory-data-analysis demo built with Python, pandas, NumPy and Plotly.

## Run the demo

From the portfolio repository root:

```bash
python -m pip install -r projects/requirements.txt
python projects/build_portfolio_demos.py
```

The script writes its synthetic input data and analysis outputs into this project folder. Open `dashboard.html` in a browser to explore the charts.

## Files

- `data/sample_students.csv` — generated learner sample.
- `data/performance_summary.csv` — score-band summary.
- `dashboard.html` — interactive report.

## Data note

All learner records are synthetic examples. Replace them only with data you are permitted to use, and protect student privacy.
